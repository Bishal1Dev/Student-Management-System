# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, respectful, and inclusive environment for everyone who contributes to the Student Management System project.

All contributors, users, and collaborators are expected to communicate professionally and respectfully regardless of background, experience level, nationality, gender, religion, or personal identity.

## Expected Behavior

Examples of positive behavior include:

- Being respectful and professional in discussions.
- Providing constructive feedback.
- Helping other contributors learn and improve.
- Respecting different opinions and approaches.
- Reporting issues clearly and responsibly.
- Collaborating openly to improve the project.

## Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment, discrimination, or personal attacks.
- Offensive or inappropriate language.
- Publishing someone's private information without permission.
- Spam, trolling, or intentionally disrupting discussions.
- Any behavior that creates an unsafe or hostile environment.

## Contribution Guidelines

When contributing to this project:

- Write clear and understandable code.
- Follow existing project structure and coding practices.
- Explain changes properly in pull requests or commits.
- Test changes before submitting contributions.
- Be open to feedback and improvements.

## Reporting Issues

If you experience or notice unacceptable behavior, please report it through the repository issues page or contact the project maintainer.

All reports will be reviewed carefully and handled respectfully.

## Enforcement

Project maintainers have the right to:

- Remove inappropriate comments or contributions.
- Reject changes that do not follow project standards.
- Restrict participation from users who violate this Code of Conduct.

Actions will be taken fairly depending on the severity and frequency of the violation.

## Scope

This Code of Conduct applies to all project-related activities, including:

- GitHub issues
- Pull requests
- Code contributions
- Discussions
- Documentation changes
